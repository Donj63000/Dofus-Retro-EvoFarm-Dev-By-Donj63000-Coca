## EvoFarm 0.3.0 — Windows, macOS et Linux

EvoFarm est désormais distribué pour les trois systèmes de bureau. L'interface, le logo, le fond, les portraits de classes et les fonctions de suivi sont conservés. Les données restent locales.

| Système | Fichier | Utilisation |
| --- | --- | --- |
| **Windows x64** | **EvoFarm.exe** ou **EvoFarm-Windows-x64.zip** | Lancer l'exécutable portable. |
| **macOS Intel et Apple Silicon** | **EvoFarm-macOS-universal.zip** | Extraire l'archive, placer `EvoFarm.app` dans Applications puis l'ouvrir. |
| **Linux x64** | **EvoFarm-Linux-x64.tar.gz** | Extraire l'archive puis lancer `./EvoFarm/evofarm`. |

**SHA256SUMS** contient les empreintes SHA-256 des quatre téléchargements.

### Intégration au bureau

- **Windows** : icône du programme, des raccourcis et de la barre des tâches ; runtime C intégré au binaire portable.
- **macOS** : bundle `.app` avec icône Finder/Dock issue de `logo.png`, et binaire universel Intel x64 + Apple Silicon ARM64. Minimum de déploiement : macOS 11.0. Les contrôles natifs s'exécutent sur macOS 15 pour les deux architectures.
- **Linux** : logo, fichier `.desktop` et script facultatif `install-desktop.sh` pour ajouter un raccourci et son icône au menu des applications de l'utilisateur. Le script référence le dossier extrait : conservez-le au même emplacement ou relancez le script après déplacement. Aucune installation automatique.

Le programme Linux est construit sur Ubuntu 22.04 x64, avec une base glibc 2.35. Un système compatible, un bureau X11 ou Wayland, OpenGL et un backend XDG Desktop Portal GTK, GNOME ou KDE sont requis. Les commandes d'installation des bibliothèques sont détaillées dans le mode d'emploi fourni.

### Première ouverture sur macOS

Le bundle macOS possède une signature ad hoc, sans certificat Developer ID ni notarisation Apple. Si macOS bloque son ouverture, essayez d'abord de lancer l'app puis accédez à **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**, et confirmez avec **Ouvrir**. Voir le [parcours officiel Apple](https://support.apple.com/fr-fr/102445).

La distribution Windows ne possède pas de signature Authenticode.

### Données et mise à jour

Fermez EvoFarm puis remplacez son programme, son bundle ou son dossier portable. Les sauvegardes et brouillons sont conservés dans le dossier de données propre au système :

- Windows : `%LOCALAPPDATA%\EvoFarm\`.
- macOS : `~/Library/Application Support/EvoFarm/`.
- Linux : `$XDG_DATA_HOME/EvoFarm/`, ou `~/.local/share/EvoFarm/`.

Pour changer d'ordinateur ou de système, transférez manuellement `data.json` puis importez cette copie dans EvoFarm. L'import remplace les données courantes ; créez une sauvegarde nommée au préalable pour les conserver. Aucune synchronisation cloud n'est ajoutée.

La CI couvre Windows 2022, Ubuntu 22.04 et macOS 15 sur Intel et Apple Silicon : formatage, Clippy, tests Rust, tests de packaging, audit des dépendances et contrôles de démarrage Linux/macOS. Les archives et leurs empreintes sont vérifiées avant publication.
